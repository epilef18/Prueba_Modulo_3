# Fundamentos de programación en Python

## Descripción

Este programa tiene como objetivo evaluar conocimientos básicos de programación en Python a través de la creación de un juego de trivia interactivo. Aplica conceptos como estructuras de datos, funciones, control de flujo y manejo de archivos. Incluye varios programas escritos en Python, que funcionan por consola y permiten al usuario jugar ejecutando main.py.

Breve explicación sobre lo que hace cada programa:

validador.py: Valida la entrada del usuario.
level.py: Determina el nivel de dificultad.
shuffle.py: Baraja las opciones de respuesta.
question.py: Selecciona una pregunta aleatoria.
print_preguntas.py: Formatea y muestra la pregunta.
verify.py: Verifica la respuesta del usuario.
main.py: Bucle principal del juego.
